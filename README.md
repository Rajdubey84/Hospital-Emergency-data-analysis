
# 🏥 Hospital Emergency Room Data Analysis

## 📌 Project Overview

This project is an **Excel-based Hospital Emergency Room Data Analysis Dashboard** developed to analyze patient visits and emergency room performance.

The analysis is performed on a **month-wise and year-wise basis** to identify patterns and trends related to patient volume, admission status, waiting time, patient satisfaction, demographics, and department referrals.

An interactive dashboard was created in Microsoft Excel to present key performance indicators (KPIs) and meaningful insights in an easy-to-understand visual format.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze the number of patients visiting the emergency room.
- Perform **month-wise and year-wise patient analysis**.
- Analyze patient admission and non-admission patterns.
- Calculate and analyze average patient waiting time.
- Analyze patient satisfaction scores.
- Identify delayed and timely patient attendance.
- Analyze patients based on gender.
- Analyze patient distribution across different age groups.
- Analyze department referral patterns.
- Create an interactive and informative Excel dashboard.
- Generate meaningful insights from hospital emergency room data.
